# Responsive Wannabe

Questo progetto è un esercizio pratico in HTML e CSS finalizzato a rendere **responsive** un sito web già esistente.  
L'obiettivo principale è stato **aggiungere adattabilità ai vari dispositivi**, consolidando le competenze nella gestione di layout flessibili e media queries.

## Tecnologie utilizzate

- HTML5
- CSS3
- Media Queries

## Obiettivi raggiunti

- Applicazione di stili CSS per rendere il layout adattabile a diverse risoluzioni
- Consolidamento delle competenze nella creazione di design responsive
- Miglioramento dell'usabilità su dispositivi mobili e desktop
